# DefiLlama Listing

Chakra is listed as a DEX aggregator on DefiLlama. The listing reports Chakra's
entry notional volume from the public analytics API; it is not TVL and does not
use hop-weighted routed volume.

- [Chakra on DefiLlama](https://defillama.com/dex-aggregators/chain/Arc)
- [Chakra stats page](https://Chakra.xyz/stats)
- [Stats API](https://api.Chakra.xyz/api/v1/stats)
- [Adapter source and methodology](https://github.com/Chakra/Arc-dex-agg/tree/main/integrations/defillama)

The upstream adapter was merged into [DefiLlama/dimension-adapters PR #8330](https://github.com/DefiLlama/dimension-adapters/pull/8330).
