# Chakra brand

Chakra is a warm, precise execution surface for non-custodial swaps across Arc Testnet venues. The visual language is dark-first, quiet, and technical: warm paper foregrounds, burnt orange actions, restrained borders, and code-native details.

## Semantic modes

Dark mode is the default product experience. Light mode uses the same semantic tokens with warm paper as the canvas and deep brown as the foreground. Components must consume semantic variables rather than hard-coded color values. The palette has no gradients.

## Typography

- DM Sans for interface text and headings.
- JetBrains Mono for addresses, numeric values, API fields, and transaction data.

## Mark

The Chakra mark is three asymmetric ring segments around a small center. It is rendered as SVG, contains no arrow, and uses the primary orange with a warm neutral secondary segment.
