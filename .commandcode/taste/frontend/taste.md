# Frontend / Web UI

- Prefers a workstation-dense, pro-terminal UI over consumer DeFi styling: compact spacing (4–12px gaps), 13–14px body, tight technical mono-heavy numbers, flat surfaces with functional borders (no glass/gradient cards), crisp <200ms motion honoring `prefers-reduced-motion`, tabular route legs, teal accent only on the primary CTA. Avoids shadcn rewrites, Inter, and purple-gradient/"DeFi blob" aesthetics. Confidence: 0.85
- Renders numeric data with `font-mono tabular-nums` and never scientific notation; null/empty values render as `--`. Confidence: 0.8
- Uses the official chain definition imported from the framework (e.g. `arcTestnet` from `wagmi/chains` / `viem/chains`) rather than defining a custom chain object; never invents an RPC URL. Confidence: 0.75
- Keeps on-screen asset/gas labels faithful to product intent: native gas is USDC (18 dp) and copy says USDC even if a wallet reports the native asset as ETH; keep native (gas) separate from ERC-20 balances and never sum the two encodings. Confidence: 0.7
- Pins the frontend test script to `NODE_ENV=development` explicitly (e.g. `"test": "NODE_ENV=development vitest run"`): production React builds omit `React.act`, which breaks `@testing-library/react` renderHook/act-based tests; the pin belongs in package.json, never assumed from the shell environment. Confidence: 0.82
- For Playwright/dAppwright MetaMask wallet harnesses, prefer mnemonic `seed:` bootstrap over private-key `importPK` (MetaMask 13 side-panel account-import UI is fragile extra surface; `importPK` stays only as a fallback and is never used for the operator key). Confidence: 0.65
- Wallet E2E (headed MetaMask) requires a real display; headless/CI cannot satisfy or evidence it — the harness must run headed on a real machine. Confidence: 0.6
- When a test harness needs an env secret, load the gitignored env file explicitly in the Playwright config (e.g. `process.loadEnvFile` on `packages/frontend/.env`): `@playwright/test` has no dotenv loader, so a secret placed only in a root `.env` never reaches `npm run qa:*`. Confidence: 0.65
- In Playwright/dAppwright wallet harnesses, when `addNetwork`/`confirmNetworkSwitch` are broken for the pinned MetaMask version (e.g. MetaMask 13.17 — `confirmNetworkSwitch` is a no-op stub and `addNetwork` drives stale extension selectors and can drop the context), complete a wallet network switch by driving the MetaMask `notification.html` popup directly: find it via `context.pages()` and click its Confirm button. Confidence: 0.7
- Token selection in the swap/selector UI must match addresses case-insensitively (`.toLowerCase()` on both sides): the API/framework catalog is lowercased while hardcoded fallback token constants (e.g. `EURC_ADDRESS`) are mixed-case, and an exact-match `find` silently makes `tokenOut` null and unmounts the Buy token selector. Confidence: 0.7
- When the shell has `NODE_ENV=production`, `npm ci`/`npm install` silently omits devDependencies (test runners like vitest disappear, and a bare install reports "up to date" as a false positive); install with `--include=dev` or unset `NODE_ENV` for dev/test tooling. Confidence: 0.7
